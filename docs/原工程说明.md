## 关卡：3 章 + 终章，共 12 件器物

| 章 | 器物 | 玩法 | 规则验证（求解器） |
|---|---|---|---|
| 第一章 · 鲁班工坊 | 鲁班锁 | 六根带榫口的木条，三个方向都能推，推到和其他木条完全分开就拆下来了 | 至少 4 步才能取出第一根，全部拆开约 12 步 |
| | 华容道 | 三局，平推木块让曹操从出口离开 | 最少 15、20、30 步 |
| | 鲁班盒 | 五块板按暗销顺序推动，盖子才能滑开 | 最少 7 步，开局只有一块板能动 |
| | 斗拱 | 13 个构件按营造顺序从下往上拼；拼好后在头顶放大五倍 | 构件按《营造法式》材分比例 |
| 第二章 · 铜作 | 文字锁 | 四个铜环齿轮联动，排出「天工开物」 | 最少 9 步，四个环都要转 |
| | 花旗锁 | 找到藏起来的锁孔，插钥匙到一半再按侧簧，最后拔出锁梁 | 最少 5 步；铜环是干扰项 |
| | 被中香炉 | 从外往里装好球壳、两层圆环和香盂；装好后香炉滚动，香盂始终水平 | 按顺序拼装 |
| | 透光镜 | 转动铜镜把灯光反射到屏风上，光斑里显出「见日之光」 | 84 种角度里只有 1 种能照中，最少 8 步 |
| 第三章 · 天工 | 指南车 | 装上齿轮和木人（有一个多余齿轮）；装好后怎么转，木人都指南 | 按顺序拼装，多余齿轮哪儿都装不上 |
| | 浑天仪 | 转动四游环、俯仰窥管，对准织女星；越接近管口越亮 | 108 种组合里只有 1 种，最少 9 步 |
| | 水运仪象台 | 按顺序装好枢轮、天池、天衡、天关、天锁和浑象；装好后一格一格走动 | 按顺序拼装 |
| 终章 | 总机关匣 | 放入鲁班尺、铜印、三垣星图，前门打开，「天工」牌匾升起 | 第一到三章全部完成才开放 |

每章的信物拼成一件宝物：鲁班尺（财病、离义、官劫、害本）、铜印「天工开物」、三垣星图（紫微、太微、天市）。

## 手势

- 捏住部件拖动：滑动类部件只沿它能动的方向走，按格吸附，推不动时有一声闷响。
- 捏住铜环、镜架、四游环上下或左右拨动：每拨 2.5 厘米转一格，联动的环跟着转。
- 捏起台上的构件拖到该在的位置，靠近时自动吸入；装早了或装错了，「匠人手记」会说明原因。
- 捏住转盘边缘左右拨动：转动鲁班锁、鲁班盒、花旗锁看背面；被中香炉和指南车装好后也能转，用来看演示。
- 「匠人手记」里的「给点提示」：第一次用金色箭头指出该动哪一件、往哪个方向；再点一次显示目标位置（滑动件的半透明影子、拼装件的槽位轮廓）。提示由求解器从当前状态实时算出。
- 「匠人手记」里还能切换环境（我的房间 / 木作工坊）、开关音乐、调整台面高度。

## 代码结构

```
app/app/src/main/java/com/vrgames/lubanbox/
├── core/      纯 Kotlin 规则和求解器，可在云电脑上单元测试
│   ├── SlidePuzzle.kt   滑动类机关的统一接口、广度优先搜索
│   ├── Burr.kt / Burrs.kt          鲁班锁：逐格碰撞、三方向移动、分段求解
│   ├── Klotski.kt / KlotskiBoards.kt  华容道
│   ├── PuzzleBox.kt / Boxes.kt     鲁班盒：暗销规则
│   ├── Assembly.kt / Dougong.kt    拼装类：插槽、依赖、吸附、干扰件
│   ├── Rotary.kt        转动类：铜环、镜架、四游环，齿轮联动和暗销
│   ├── Bronze.kt / Celestial.kt    第二、三章和终章的器物数据（含透光镜反射、浑天仪指向的几何计算）
│   ├── Relics.kt        器物目录、目标、史料
│   └── Workshop.kt      当前器物、局数、分级提示、存档
├── game/      Game（三个空间共享的状态）、AutoPilot（调试用自动通关）
├── render/    Bench（工作台和转盘）、Scenes（每件器物的摆放和演示动画）、SlideView、RotaryView、
│              AssemblyView、Assets、Sound、Music、Effects（星屑）
└── content/   WorkshopStage（全空间）、AtlasWindow（营造图谱）、NotesWindow（匠人手记）
tools/         Blender 脚本：make_burr / make_klotski / make_box / make_dougong / make_bronze /
               make_celestial / make_tokens（模型），make_metal_tex（金属贴图），make_workshop（工坊全景）、make_sky（全景贴上的内翻球），
               make_atlas（图谱线描图），make_icon（图标），preview（预览渲染）；
               extract_points（从模型取表面点给单元测试核对碰撞形状）、audit_meshes（拼装类器物的网格穿插审计，v0.10.1）
```

## 构建与测试

```bash
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug
# 设计实验（鲁班锁榫口搜索、华容道布局搜索、导出建模数据）：
./gradlew --no-daemon testDebugUnitTest --tests '*Lab*' --tests '*ModelDataExport*' -Dlab=true
# 模型（需要 Blender 4.2，贴图见 docs/素材来源.md）：
blender -b --factory-startup --python ../tools/make_burr.py -- ../tools/data/burr.json app/src/main/assets/models/burr.glb
```

## 模拟器自动测试（仅 debug 版）

```bash
B="adb shell am broadcast -a com.vrgames.lubanbox.TEST -p com.vrgames.lubanbox --es cmd"
$B all                      # 按求解器的步骤依次打开全部 12 件器物
$B relic --es id klotski    # 把某件器物放到工作台上
$B solve                    # 自动解开当前器物
$B hint                     # 要一次提示
$B view --es id "x,y,z,yaw,scale"   # 把工作台挪到模拟器的固定视角前（reset 复原）
$B turn --es id 30          # 转台转 30 度
$B env                      # 切换「我的房间 / 木作工坊」环境
$B music                    # 背景音乐开关
$B sky --es id "0,90,0"     # 工坊全景转个角度（检查贴图朝向用）
$B boxplay                  # 鲁班盒：用手拖的方式按顺序打开，记录每块板的余量和穿插（v0.10.1）
$B slidedrag --es id "1,x,25"   # 拖动工作台上的某块滑动件（件号,轴,毫米）
adb logcat -s LubanTest
```
